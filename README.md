# Ассистент рекрутера — бриф → вакансия, каналы, кандидаты, сравнение

Веб-приложение для рекрутеров. Рекрутер вставляет бриф — и мгновенно получает:

1. **Вакансию** — переписанный текст для публикации в трёх вариантах (энергичный, корпоративный, короткий тизер для Telegram).
2. **Сильный бриф** — контекст, ключевые задачи (outcome), профиль (must-have), **рамку роли** («не X, а Y»), **анти-профиль** (стоп-факторы), метрики, условия и проверку на реализм рынка.
3. **Стратегию поиска и каналы** — смежные пулы, компании-доноры, сигналы-триггеры, каналы (конференции, сообщества, Telegram, премии), реферальные ходы и Boolean/X-ray строки.
4. **Кандидатов из открытых источников** — лонг-лист реальных людей по публичным профессиональным источникам (OSINT через веб-поиск) с указанием источника и уверенности.
5. **Сравнение резюме с брифом** — загрузите резюме, получите оценку соответствия (0–100), разбор по must-have, сильные стороны/пробелы и рекомендацию по каждому кандидату.

Всё это привязано к **позиции** — сохраняемому объекту, к которому можно вернуться.

### Системная часть: позиции, доска и экспорт

- **Позиции и аккаунты.** У каждого рекрутёра свой логин; каждый поиск — отдельная позиция (бриф, вакансия, стратегия, кандидаты), которая хранится на сервере (PostgreSQL) и доступна с любого устройства. К любой позиции можно вернуться.
- **Доска подбора (kanban).** Кандидаты из OSINT-поиска и из сравнения резюме попадают на **одну доску** и двигаются по этапам: Лонг-лист → Аутрич → Интервью → Финал / Отказ. Можно добавлять кандидатов вручную, писать заметки, менять этап. Это и есть системная связка двух потоков кандидатов в единый пайплайн.
- **Глубокое OSINT-досье.** По любому кандидату с доски — кнопка «Собрать OSINT-досье»: якоря личности и предупреждение об однофамильцах, слои источников со статусами (проверено / недоступно / расхождение), датированные находки, **публичные профессиональные ссылки для аутрича** (профиль на сайте, канал, доклад — без приватных контактов), красные флаги, взвешенная оценка по критериям из брифа (веса ×2 / ×1.5 / ×1) и вывод для ГД. Досье сохраняется на карточке.
- **Письма для аутрича.** По кандидату — кнопка «✉ Письма для аутрича»: 3 персонализированных сообщения (прямое кандидату, запрос рекомендации у коннектора, короткий тизер) на основе брифа и досье, с кнопкой «Копировать». Тон и логика — из практики аутрича (крючок статуса, просить наводку, а не резюме).
- **Загрузка резюме файлом.** В сравнении можно не вставлять текст, а загрузить **PDF, DOCX или TXT** — текст извлекается автоматически (DOCX/TXT — локально, без модели; PDF — нативным document-входом модели).
- **Экспорт.** Бриф + вакансия + стратегия — в **.docx** (готовый Word) и **.md**; доска кандидатов — в **.csv** для Excel/ATS.

Методология перенесена из практики executive search: рамка роли и анти-профиль, контраст «не X, а Y», outcome вместо активностей, креативный сорсинг и этичный OSINT только по публичным данным.

## Стек

- **Next.js 14** (App Router) + TypeScript + Tailwind CSS
- **Anthropic SDK** на сервере (`claude-opus-5` по умолчанию), adaptive thinking + effort
- Веб-поиск (`web_search`) для поиска кандидатов по открытым источникам
- Structured outputs для надёжного JSON

## Запуск

```bash
npm install
cp .env.example .env.local   # и впишите ANTHROPIC_API_KEY
npm run dev                  # http://localhost:3000
```

### Переменные окружения

| Переменная          | Назначение                                                        |
| ------------------- | ----------------------------------------------------------------- |
| `ANTHROPIC_API_KEY` | Ключ Anthropic API. Без него — **демо-режим** (пример без модели). |
| `ANTHROPIC_MODEL`   | Модель, по умолчанию `claude-opus-5`. Можно `claude-sonnet-5`.    |

**Демо-режим:** без ключа приложение полностью проходимо и показывает пример
на роли «Директор по МТО» — удобно посмотреть интерфейс и структуру ответа.

## Аккаунты и общий доступ (SaaS)

Приложение многопользовательское: у каждого рекрутёра свой **логин**, позиции
хранятся в **PostgreSQL** и доступны с любого устройства. Вы разворачиваете один
экземпляр, делитесь ссылкой — рекрутёры регистрируются и работают независимо.

**Переменные окружения:**

| Переменная          | Обязательно | Назначение                                                            |
| ------------------- | ----------- | --------------------------------------------------------------------- |
| `ANTHROPIC_API_KEY` | для «живого» | Ключ Anthropic. Без него — демо-режим.                                |
| `DATABASE_URL`      | да (прод)   | Строка подключения PostgreSQL. Без неё — in-memory (данные теряются). |
| `SESSION_SECRET`    | да (прод)   | Секрет для подписи сессий. `openssl rand -hex 32`.                    |
| `INVITE_CODE`       | нет         | Если задан — регистрация только по этому коду. Раздайте рекрутёрам.   |
| `ANTHROPIC_MODEL`   | нет         | Модель, по умолчанию `claude-opus-5`.                                 |

Проверка после деплоя: `/api/status` → `{"live":true,"db":true,...}`.

## Деплой на Timeweb Cloud (аккаунты + база)

1. **База.** В панели Timeweb Cloud → *Базы данных* → создайте **PostgreSQL**.
   Скопируйте строку подключения (host, порт, пользователь, пароль, имя БД) —
   это `DATABASE_URL` вида `postgres://user:pass@host:5432/dbname`.
2. **Приложение.** *Apps / Приложения* → создать из **GitHub-репозитория**
   (`ademeshkina-web/recruiter`, ветка `main`). Тип — **Docker** (в репозитории
   есть `Dockerfile`).
3. **Переменные окружения** приложения: `ANTHROPIC_API_KEY`, `DATABASE_URL`,
   `SESSION_SECRET`, при желании `INVITE_CODE`.
4. Deploy → публичная ссылка. Таблицы создаются автоматически при первом старте.
5. **Поделитесь ссылкой** (и кодом приглашения, если задали `INVITE_CODE`) —
   рекрутёры регистрируются сами и работают каждый в своём аккаунте.

> Порт по умолчанию — `3000`. Если Timeweb задаёт свой порт через переменную
> `PORT`, приложение её подхватывает (standalone-сервер Next.js).

### Docker (любой сервер / VPS)

```bash
docker build -t recruiter .
docker run -p 3000:3000 \
  -e ANTHROPIC_API_KEY=sk-ant-... \
  -e DATABASE_URL=postgres://user:pass@host:5432/dbname \
  -e SESSION_SECRET=$(openssl rand -hex 32) \
  -e INVITE_CODE=teamcode \
  recruiter
```

### Vercel (альтернатива)

Работает так же: импортируйте репозиторий, задайте те же переменные окружения
(для БД подойдёт любой managed PostgreSQL — Neon, Supabase, Timeweb).
`vercel.json` поднимает лимит функций до 300 сек (план Pro).

## Этика OSINT

Поиск кандидатов использует только **публичную профессиональную** информацию и
только для целей найма. Приложение не собирает контакты, телефоны, домашние
адреса и чувствительные данные. Лонг-лист — это гипотезы для аутрича, а не факт
готовности человека сменить работу.
